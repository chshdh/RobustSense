## 主要注册结论

Robust Gated Fusion 在受控完整模态 Macro-F1 上以 0.6043 领先。Quality-Aware Fusion 在自然缺失 Macro-F1 上以 0.5781 领先，比普通 Gated 高 0.0110，并在全部五个配对外层 fold 中获胜。污染感知方法能够降低多模态移除造成的退化。

可靠度输出会随受控污染单调响应，但门控权重不会始终降低遭受 Gaussian 或 bias 污染的模态权重，因此 H4 仅得到部分支持。最终材料必须保留这一区别。
