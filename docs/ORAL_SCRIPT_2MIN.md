# RobustSense 两分钟口头介绍

## 完整讲稿

我的项目叫 RobustSense，研究的是传感器缺失或数据异常时，多模态上下文识别模型如何保持稳定。

项目使用 ExtraSensory 数据集，共 60 名用户、377,346 条分钟级记录。我选择手机加速度计、手机陀螺仪、手表加速度计、位置、音频和手机状态六个模态，共 177 个预计算特征，预测坐着、走路、睡眠、在家、室内等 15 个可同时成立的上下文标签，因此任务采用独立 sigmoid 和带掩码 BCE；未知标签不会被当成负类。

模型先用六个独立编码器把异构模态映射到统一的 64 维空间。每个模态还计算可用性、观测比例、异常值比例等五个质量特征，ReliabilityNet 据此估计可靠度，Gate 再结合内容、质量和可靠度分配融合权重。不可用模态通过 masked softmax 获得精确的零权重。

为了让模型真正学会应对故障，我在训练阶段加入 Sensor Dropout，并注入 Gaussian 噪声、偏置漂移和尺度误差。实验严格按用户进行五折划分，预处理只拟合训练用户，阈值只由验证集选择。最终 60 个可信实验单元全部成功。

结果显示，Robust Gated 在完整模态条件下的 Macro-F1 最高，为 0.6043；Quality-Aware 在自然缺失条件下最高，为 0.5781，比普通 Gated 提高 0.0110，并在五个 fold 中全部获胜。随机移除三个模态时，普通 Gated 的相对下降为 12.87%，Quality-Aware 降至 9.45%。

实验也发现，可靠度输出会随污染增强而下降，但门控权重不会在所有故障下同步下降。因此我把门控权重解释为任务相关的分配，而不是经过校准的传感器可靠度。项目还实现了读取真实检查点和测试样本的 Streamlit 离线故障回放，用于检查模型行为，但它不是实时传感器系统。

## 必须保持准确的表述

- 说“特征空间污染”，不要说“真实物理传感器故障仿真”。
- 说“五折、单种子描述性结果”，不要说“统计显著”或“最先进性能”。
- 说“可靠度响应符合预期，门控权重假设部分成立”，不要把二者混为一谈。
