# Phase 3 报告

日期：2026-09-10（Asia/Shanghai）

## 结果

Phase 3 已按预定义开发协议通过验收：ExtraSensory 官方外层 fold 0、验证 fold 1、种子 13、一个 epoch，以及冻结的 Phase 2 处理数据。B4、B5、仅分类损失的 P 和带可靠度/一致性损失的 P 均已在本地 RTX 2060 上完成。

这只是工程验证，不构成模型排序或鲁棒性结论。阈值仍由验证集产生；确定性污染探针只用于诊断，没有用于选择模型或调节阈值。

## 已实现模型

- B4 `gated`：六个模态编码器、逐模态内容门控、可用性掩码 softmax、加权嵌入融合和共享多标签分类器。
- B5 `robust-gated`：在确定性 Sensor Dropout 和特征空间噪声视图上训练的 B4 架构。
- P-cls `quality-aware-cls`：在 B5 上增加五个部署可观测质量值和逐模态 ReliabilityNet，初始只使用分类损失训练。
- P `quality-aware`：在 P-cls 上增加可靠度 MSE 与干净/污染预测一致性 MSE，权重均为 0.1。

模型前向只接收特征、特征掩码、模态可用性和五个可观测质量值，不需要人工故障类型或强度，因此移除这些仅训练字段后仍可执行部署推理。

## 确定性污染合同

每次训练抽样由全局种子、epoch、用户 ID、时间戳和视图名称共同确定。冻结混合视图策略以 0.8 概率施加污染，按 0.4/0.4/0.2 概率采样 0/1/2 个缺失模态，并以 0.3 概率向一个剩余模态添加 Gaussian、bias 或 scale 噪声。缺失数会截断，确保至少保留一个自然可用模态。

人工污染不会改变目标或目标掩码。质量值根据污染后的可观测特征重新计算。人工类型和强度只作为诊断元数据，不输入模型。可靠度目标定义为：干净可用模态为 1、缺失模态为 0、噪声模态为 `1 - normalized_severity`。

## 验收证据

- 单元测试覆盖干净、缺失和 Gaussian 噪声场景，确定性掩码/噪声重放，标签张量不变以及至少保留一个模态的不变量。
- 带掩码 softmax 会拒绝全部模态不可用的样本，使不可用模态权重精确为零，并使可用权重和为一。
- 不提供人工故障元数据时，质量感知前向仍可成功执行。
- 官方 fold 诊断审计发现：不可用模态上的非零权重为零；探针中全部模态禁用的样本为零；观测到的最大权重和绝对误差为 `1.1920928955078125e-07`（float32 舍入）。
- 每个 run 保存 414,930 条长表模态记录：65,059 个自然测试样本加 4,096 个固定污染探针样本，每样本六个模态。每个确定性探针包含 3,546 条人工故障模态记录。
- 小型官方结构集成夹具端到端训练并评估 B2、B4 和 P，同时校验检查点、验证阈值、指标、预测和模态诊断。

## Run 产物

四个 `runs/extrasensory-*-fold0-seed13-dev/` 目录包含解析后配置、环境和数据合同、分项损失训练日志、检查点、验证集派生阈值、验证/测试指标、Parquet 预测和 `modality_diagnostics.parquet`。诊断行包括融合权重、预测可靠度、自然/污染后可用性、人工故障标志/类型/强度及被丢弃模态状态。

## 剩余限制与下一阶段

Phase 3 只证明实现合同，尚未在共享完整样本子集上比较模型或报告强度曲线。Phase 4 将实现自然缺失与受控完整子集污染两条独立评估线、E1–E8、可追溯聚合表/图、run 完整性检查和幂等报告生成。
