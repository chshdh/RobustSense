# RobustSense 数据卡：ExtraSensory 预计算特征

## 数据集与预期用途

RobustSense 使用 ExtraSensory 官方预计算特征与标签数据，研究自然模态缺失和人工模态污染下、用户独立的多标签上下文识别。本地审计覆盖 60 名用户、377,346 条分钟级记录。项目不重新分发原始归档。

数据仅用于离线模型开发与评估，不是实时感知流或临床数据，也不能证明模型能泛化到当前手机、可穿戴设备、其他国家、年龄组或部署环境。

## 本地来源与完整性

官方归档应存放在 `data/raw/`，该目录被 Git 忽略。本地记录的 SHA-256 仅用于检查已下载副本的连续性，不是发布方签名的官方校验和。解压逻辑会拒绝路径穿越、绝对路径、链接、重复目标和损坏的 ZIP 文件。

权威本地审计产物：

- `reports/data_audit/dataset_summary.json`
- `reports/data_audit/feature_schema.csv`
- `reports/data_audit/label_prevalence.csv`
- `reports/data_audit/label_by_fold.csv`
- `reports/data_audit/modality_missingness.csv`
- `reports/data_audit/user_sample_counts.csv`
- `reports/data_audit/audit_report.md`

## 模式定义

官方表头共有 278 列：时间戳、225 个特征列、51 个标签和标签来源元数据。RobustSense 选择 177 个特征，分为六个模态：

| 模态 | 选用特征数 |
|---|---:|
| phone_acc | 26 |
| phone_gyro | 26 |
| watch_acc | 46 |
| location | 17 |
| audio | 28 |
| phone_state | 34 |

另有 48 个特征被明确忽略，不会无声遗漏。任务选用 15 个上下文标签。标签值必须为 `0`、`1` 或 `NaN`；`NaN` 表示未知，而不是负类。

## 数据行与排除规则

377,346 条审计记录中，372,168 条可进入预处理。恰有 5,178 条记录的 15 个标签全部未知，按预先声明的规则排除。没有记录同时缺少全部六个模态。键 `(user_id, timestamp)` 唯一。

自然传感器可用性作为输入掩码保留，缺失特征不会被视为真实零值。审计表保留逐标签已知/正/负样本数及各 fold 的正例用户数。

## 用户级划分与防泄漏控制

官方五折用户分配作为外层测试划分。对每个外层 fold，验证用户从另一个用户 fold 中确定性选取，其余用户用于训练。每个处理清单记录精确的用户哈希。

中位数填补、稳健缩放、可观测质量统计量、类别权重、早停和逐标签阈值只使用训练集或验证集拟合。测试用户不参与预处理拟合或阈值选择。

## 自然与受控评估总体

自然缺失评估使用每一条合法测试记录，并保留原始模态可用模式。受控评估从六模态完整的测试总体开始，在同一 fold 内固定各场景的样本 ID。fold 0–4 的完整模态总体分别有 35,613、42,146、59,898、48,501 和 22,393 条记录。

完整模态总体是经过选择的子集，可能与自然缺失记录存在系统差异。因此，受控结果和自然结果必须同时报告。

## 隐私与伦理

ExtraSensory 包含来自个人设备的行为上下文。即便仅使用预计算特征和匿名用户标识，活动、位置、音频和设备状态信息仍可能敏感。RobustSense：

- 不尝试重新识别用户；
- 不在公开报告中暴露原始逐用户样本；
- 不把模型描述为监控工具；
- 将下载数据和生成的 run 产物排除在 Git 之外；
- 仅报告聚合 fold 统计，并只提供离线回放。

重新分发或部署衍生产物前，使用者必须审查原数据集条款及适用的隐私要求。

## 已知限制

该数据集年代较早，标签由用户自报，且在人群、地域和设备方面受限，可能存在标签噪声和设备代际偏差。缺失可能与行为有关，因此不一定是随机缺失。预计算特征也使本项目无法验证原始信号处理和物理故障模型。基于本数据训练的模型不得用于安全关键、医疗、就业、保险或个人监控决策。

## 复现

完整审计前先运行模式探针：

```powershell
.\scripts\fetch_extrasensory.ps1
.\scripts\run_phase1_audit.ps1 -ProbeOnly
.\scripts\run_phase1_audit.ps1
```

完整审计必须复现本数据卡中的计数，并在模式、标签值域、重复键、归档完整性或用户隔离违规时失败。
