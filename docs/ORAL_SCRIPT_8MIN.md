# RobustSense 八分钟口头汇报

## 0:00–0:45 研究问题

我的项目叫 RobustSense。它关注一个现实问题：多传感器上下文识别通常假设全部输入一直可用，但真实设备中，手表可能没有佩戴，位置可能漂移，音频可能受噪声干扰。如果模型长期依赖某一路传感器，这一路缺失或异常后，预测就可能明显退化。因此本项目研究的重点不是一般意义上的多模态融合，而是传感器不完整、不稳定时如何进行鲁棒融合。

## 0:45–1:35 数据与任务

项目使用 ExtraSensory 官方预计算特征数据。审计后共有 60 名用户、377,346 条分钟级记录。原数据包含 225 个特征，我选择六个模态中的 177 个特征：手机加速度计 26 个、手机陀螺仪 26 个、手表加速度计 46 个、位置 17 个、音频 28 个、手机状态 34 个。

模型预测 15 个上下文标签。一条记录可以同时是“坐着、使用电脑、在家、室内”，所以这是多标签任务，不使用单一 softmax，而是为每个标签独立输出 sigmoid 概率。标签中的 NaN 表示未知，不代表负类，因此训练损失和评估指标都会屏蔽未知标签。

## 1:35–2:20 防泄漏处理

实验按用户划分，而不是随机按数据行划分。同一人的不同时间记录通常高度相关，如果同一用户同时出现在训练和测试中，模型可能记住用户或设备特征，得到虚高结果。项目采用官方五折：当前 fold 作为测试，下一个 fold 作为验证，其余三个 fold 训练，训练、验证和测试用户完全互斥。

每个 fold 的中位数填补、IQR 稳健缩放和类别权重都只用训练用户拟合。逐标签决策阈值只在验证集的 0.05 到 0.95 网格上选择，之后在所有测试故障场景中保持不变。

## 2:20–3:35 模型结构

六种模态的维度和物理意义不同，因此分别进入独立编码器。编码器同时接收特征和 feature mask，把每个模态转换成 64 维内容表示。feature mask 用于区分真实零值和因缺失而填入的零值。

随后，每个模态计算五个可观测质量特征：是否可用、观测比例、异常值比例、稳健 z-score 绝对值均值和最大值。ReliabilityNet 根据内容表示和质量特征输出可靠度。Gate 再结合内容、质量和可靠度产生模态分数，通过带可用性掩码的 softmax 转成权重。不可用模态权重严格为零，其余模态权重和为一。最终对六个模态表示加权求和，再由分类器输出 15 个标签概率。

可靠度和融合权重需要区分。可靠度回答“这一路数据看起来是否正常”，融合权重回答“为了当前分类任务应该使用它多少”。可靠的位置特征对判断说话可能仍然帮助有限，所以可靠度高不代表权重一定高。

## 3:35–4:30 鲁棒训练

模型具备 Gate 不等于它自然学会应对故障，因此训练阶段主动制造故障。Sensor Dropout 会关闭整个模态，区别于普通 Dropout 随机关闭神经元。训练还会向一个剩余模态注入三类特征空间污染：Gaussian 随机扰动、整体偏置和整体尺度变化，并保证至少保留一个自然可用模态。

Quality-Aware 模型的总损失由三部分组成：分类损失保证标签预测，可靠度损失让 ReliabilityNet 学习干净、缺失和污染模态的可靠程度，一致性损失限制同一样本在轻度污染前后出现不合理的预测跳变。

## 4:30–5:25 比较方法与实验

正式可信矩阵包含十二个模型。六个单模态模型用于判断每路信息单独的能力；线性和 MLP 早期融合、后期融合提供基本融合基线；B4 Gated 检验动态权重；B5 Robust Gated 在相同架构上加入故障增强；最终 P Quality-Aware 再加入显式质量特征和 ReliabilityNet。

评估分为两条线。自然缺失评估使用全部合法测试记录并保留原始可用性。受控故障评估从六模态完整记录开始，在同一批样本上逐步移除或污染模态，使性能变化主要来自注入故障。受控场景包括逐一移除、随机移除一个到三个模态，以及不同强度的 Gaussian、偏置和尺度污染。

## 5:25–6:30 主要结果

五折、种子 13 的 60 个可信实验单元全部完成。完整模态条件下，普通 Gated、Robust Gated 和 Quality-Aware 的平均 Macro-F1 分别为 0.5995、0.6043 和 0.6022。Robust Gated 最好，但相对普通 Gated 的增益只有约 0.0048，因此项目的核心价值不是干净输入上的大幅提升。

自然缺失条件下，三者分别为 0.5670、0.5757 和 0.5781。Quality-Aware 比普通 Gated 平均提高 0.0110，并在五个外层 fold 中全部获胜。

随机移除三个模态时，普通 Gated 的相对 Macro-F1 下降为 12.87%，Robust Gated 为 10.33%，Quality-Aware 为 9.45%。这说明污染感知训练能够降低多模态缺失造成的退化，显式质量建模在较强缺失下进一步表现出优势。

## 6:30–7:15 负面发现与解释

对 Quality-Aware 而言，预测可靠度与 Gaussian、偏置和尺度污染强度的平均 Spearman 相关分别约为 -1.00、-0.98 和 -0.93，说明可靠度会随污染增强而降低。

但目标模态门控权重在 Gaussian 和偏置条件下的平均相关为正，只在尺度误差下为负。因此 H4 只能判定为部分支持。这个结果说明门控权重同时反映可靠性、任务效用和模态竞争，不能直接解释为经过校准的传感器可信度。项目保留了这一负面结果，没有只选择支持假设的图表。

## 7:15–8:00 工程实现、限制与结论

工程上，项目建立了可恢复的 run 注册表，保留每次尝试和协议哈希；报告生成器会检查 fold、种子、模式、阈值和受控样本 ID，并从真实 run 生成表图。Streamlit 演示读取真实检查点、预处理器、验证阈值和测试样本，允许离线注入故障并比较 B4、B5 和 P。

项目限制包括：可信矩阵只有一个训练种子；A0–A5 消融只在一个 fold 上短期运行；受控完整子集存在选择偏差；污染作用于预计算特征而不是原始信号；没有第二个数据集和端侧实时验证。

因此最终结论是：在 ExtraSensory 和冻结协议下，污染感知训练降低了模态缺失退化，Quality-Aware 取得最佳自然缺失 Macro-F1，并学习到对污染敏感的可靠度信号；但完整输入增益较小，门控权重也不能视为可靠度解释。项目的贡献是一个可复现、边界清楚的鲁棒多传感器融合实现和评估闭环。
