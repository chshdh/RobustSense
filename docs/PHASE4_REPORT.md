# Phase 4 报告

日期：2026-09-10（Asia/Shanghai）

## 结果

Phase 4 已针对冻结开发矩阵通过验收：ExtraSensory 官方外层 fold 0、种子 13、单 epoch 检查点、全部 13 个注册模型 run 和评估套件版本 1。实现现已提供相互独立的自然缺失与受控完整模态评估、E1–E8 输出、run 矩阵验证、可追溯表/图和幂等技术报告草稿。

这些是工程结果，不是可信的多折研究发现。没有使用测试结果调节阈值、检查点、场景或样本集。

## 评估集合与场景

- 自然评估线：使用每条合法测试记录。融合模型评估全部 65,059 行；B0 单传感器 run 在其唯一模态不可用时明确弃权。
- 受控评估线：测试 fold 中有 35,613 条六模态完整记录。dev 套件按冻结场景种子排序 ID，并为每个模型和场景使用同一组 4,096 个 ID。ID 列表 SHA-256 为 `8e9dca83afbff5da88855b12483fd9da5627b91174267881a54b888529744363`。
- B2、B3、B4、B5、P 各评估 88 个受控条件：1 个干净条件、6 个逐一缺失、15 个固定 drop-k 掩码、24 个 Gaussian、18 个 bias 和 24 个 scale 场景。
- Gaussian 各强度复用同一确定性基础噪声方向，只改变幅值。bias 与 scale 是确定性的标准化特征空间压力测试，均不代表物理硬件噪声。

## E3–E6 退化证据

- E3 最差单模态移除相对损失：移除 location 时 B2 为 13.55%；移除 watch acceleration 时 B3 为 7.28%、B4 为 6.81%、B5 为 4.71%；移除 phone state 时 P 为 4.58%。
- E4 移除三个模态的平均相对损失：B2 16.78%、B3 13.94%、B4 8.94%、B5 8.01%、P 7.68%。dev 图中的误差条是五个固定掩码间标准差，不是 fold 不确定性。
- E5 在 Gaussian sigma 2.0 下对六个目标模态取平均，相对各自干净分数，B2/B3/B4/B5/P 分别损失 9.42%/3.59%/2.99%/3.32%/3.89%。
- E6 最强配置 bias 下，B5 与 P 的平均损失分别为 1.14% 和 1.21%。短 run 中 scale 影响较小，偶尔会提高得分；负退化值原样保留，不裁剪。

以上观察仅描述该 dev 检查点，在五折评估前不能据此接受或拒绝鲁棒性假设。

## E7 质量响应

对 P 而言，全部六个受损模态的预测可靠度与 Gaussian 强度的 Spearman 相关均为 -1.0；四个 Gaussian 强度点的平均可靠度 MAE 为 0.4042–0.4440。融合权重响应混合：audio（-0.8）和 phone state（-1.0）随强度下降，而 location、phone accelerometer、phone gyroscope 和 watch accelerometer 上升（+1.0）。

因此，该 dev run 支持可靠度响应，但不能证明每个受损模态的门控权重都会单调下降。对于不输出可靠度/权重的模型，生成表保留 `NaN`，不以零替代。

- 聚合代码报告非空计数，将不可用的均值/标准差保留为 `NaN`，绝不替换为零。单 fold 的 fold 级标准差正确标记为不可用；场景误差条按固定掩码或目标模态变异计算并明确标注。
- 连续两次生成报告后，全部 28 个跟踪输出字节级完全一致。
- 小型官方结构集成夹具在全部 88 个场景上评估 B2/B4/P，验证报告矩阵，并检查重复生成的报告哈希。

## 剩余限制与下一阶段

dev 检查点只有一个 epoch、一个 fold 和一个种子。受控评估只使用 35,613 条完整记录中的确定性 4,096 条子集；可信评估必须移除这一 dev 限制。完整子集存在选择偏差，自然评估线中不同单传感器模型的可用样本数也不相等。

`ablation.png` 只表示架构/损失演进，不是正式 A1–A5 消融矩阵。Phase 5 必须先冻结并训练这些消融，才能作因果结论；随后建立 run 注册表、执行五折可信矩阵、保留失败/重试，并以 fold 均值和标准差重新生成 Phase 4 输出。
