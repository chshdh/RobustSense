# ADR-0001：V4-1 标签级可靠融合

## 状态

已接受；这是 RobustSense 最后一次模型结构优化。

## 背景

P2 为每个样本生成 6 个模态权重，所有 51 个活动标签共享同一个融合向量。但 GPS、音频、加速度计等模态对不同标签的作用不同。V3 已证明仅在预测后增加置信度选择器只能带来约 0.003～0.007 的风险改善，无法修正基础分类错误。

## 决策

构建 `P2-LC`：保留 P2 的模态编码器、物理可靠度、可靠度约束强度和分类器，只把效用输出从“每模态 1 个”扩展为“每模态 × 每标签 1 个”，从而产生 `[样本, 标签, 模态]` 融合权重。

候选模型从相同 fold/seed 的 P2 检查点做等价展开。展开时把原标量效用复制到全部标签，因此微调前每个标签的权重和最终预测概率必须与 P2 在 `1e-6` 内一致；GPU 线性层内核造成的 logit 舍入差另设 `1e-5` 诊断上限。训练时冻结继承的 P2 主干，只更新标签条件效用网络，避免把额外训练轮数伪装成结构收益，并将训练成本控制在最后一次实验可接受范围内。

## 后果

候选模型参数略增，但不会从零重新训练。若五折三种子结果未达到预声明的 `+0.010` Macro-F1，则判定该路线没有形成有意义提升，项目停止增加模型版本，保留负结果并进入收尾。
