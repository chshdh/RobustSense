# RobustSense V4-1 实验协议：最后一次标签级可靠融合优化

## 1. 研究问题

在保持 P2 编码器、物理可靠度与分类器不变的条件下，仅把共享模态路由升级为标签条件路由，能否在自然缺失测试集上获得至少 0.010 的 Macro-F1 绝对提升？

## 2. 模型与等价初始化

P2 的效用为 `u(i,m)`，所有标签共享融合权重。P2-LC 将其改为 `u(i,m,l)`：

\[
w_{i,l,m}=\operatorname{softmax}_m\left(u_{i,m,l}+\beta\log(r_{i,m}+\epsilon)\right).
\]

每个标签使用自己的融合向量，但继续共享 P2 的物理可靠度 `r`。候选模型从同 fold/seed 的 P2 展开；展开前后最终预测概率和各标签权重最大绝对差不得超过 `1e-6`。由于 GPU 二维与三维线性层可能使用不同矩阵乘内核，未归一化 logit 另设 `1e-5` 的数值诊断上限。

## 3. 训练边界

- 5 折 × 3 种子，共 15 个候选单元。
- P2 主干全部冻结，只训练标签条件效用网络。
- 只使用 train 计算梯度，validation 用于早停和逐标签分类阈值。
- epoch 0 的等价 P2 状态可作为最佳检查点，防止 validation 明显退化。
- test 在训练完成、检查点和阈值冻结后由独立评估步骤打开一次。
- 不允许根据 test 选择 epoch、学习率、种子或模型版本。

## 4. 预声明判据

首要成功必须同时满足：

1. 五折等权聚合的自然缺失 Macro-F1 相对 P2 至少提升 `+0.010`；
2. 至少 3/5 折的配对 Macro-F1 为正。

安全闸门：Micro-F1 差值不低于 `-0.005`，masked BCE 增量不超过 `+0.005`，参数量增幅不超过 25%，推理延迟增幅不超过 50%。完整性验收与科学成功分开记录。

## 5. 停止规则

这是最后一次模型优化。无论首要判据是否通过，V4-1 完成后均不再增加 V5 或新的模型结构，只进行结果整理、演示与面试答辩准备。
