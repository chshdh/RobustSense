# Phase 2 报告

日期：2026-09-10（Asia/Shanghai）

## 结果

Phase 2 已按预定义开发协议通过验收：官方外层 fold 0、验证 fold 1、种子 13、一个 epoch。fold 专属稳健预处理、带掩码加权 BCE、仅由验证集选择的逐标签阈值、B0–B3、检查点合同、指标和 Parquet 预测均已在本地 RTX 2060 上使用真实 ExtraSensory 数据完成。

这只是工程验证，不是可信的多折研究结果。没有根据测试性能选择模型或超参数。

## 防泄漏预处理

- 冻结输入：Phase 1 模式中的 177 个选用特征和 15 个标签。
- 划分：36/12/12 名训练/验证/测试用户，并保存用户列表哈希。
- 源记录/保留记录：训练 238,005/232,827；验证 74,282/74,282；测试 65,059/65,059。
- 排除的 5,178 条训练记录均因 15 个标签全部未知；没有记录因全部模态不可用而被排除。
- 中位数、IQR、常量列回退、裁剪和异常值阈值只由训练用户拟合；验证和测试转换复用保存的数组。
- 仅在稳健缩放后将 NaN 置零，并保留原始特征掩码。
- 每个模态有五个部署时可观测的质量值：可用性、观测比例、异常值比例、稳健 z-score 绝对值均值和最大值。

## 已实现基线

- B0：六个模态专属编码器/分类器。单一模态不可用的样本不计入该模型的损失、类别权重或指标。
- B1：对缩放特征、特征掩码和可用性执行线性早期融合。
- B2：使用共享隐藏/潜在维度的 MLP 早期融合。
- B3：六个模态专属分类器，按可用性掩码平均 logit。

所有模型均输出统一合同。B3 将不可用模态权重精确设为零，并使可用权重和为一。

## 有效性检查

- 手工 Torch batch 中，未知标签的梯度贡献精确为零。
- 测试集专属极值不改变训练中位数/IQR；常量列使用 IQR 1，缺失标准化值变为零。
- 阈值调节拒绝验证集之外的任何来源划分。
- 检查点评估拒绝模型/模式/预处理器/标签合同不匹配。
- 使用种子 13 重跑 B1 时，Macro-F1、Micro-F1、mAP 和完整阈值产物完全一致。
- 确定性打乱训练标签后，验证 mAP 为 0.217674，平均标签流行率基线为 0.222293，绝对差 0.004619；此检查没有读取测试 fold。

## 剩余限制与下一阶段

短期 dev 配置不能确定模型排序或鲁棒性。Phase 3 将实现 B4 门控融合、确定性缺失/噪声污染、B5 鲁棒门控融合和质量感知方案 P，并保持 Phase 2 的模式、预处理器、划分、标签掩码、类别权重来源和验证阈值规则不变。
