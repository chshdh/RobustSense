# RobustSense 答辩问题库

## 项目定位

### 1. 这个项目一句话解决什么问题？

研究多源传感器发生自然缺失或特征异常时，如何通过故障增强、质量建模和动态门控保持多标签上下文识别性能。

### 2. 为什么不只是普通的多模态分类？

普通融合主要关注完整输入下如何组合信息。本项目把输入可用性和质量变化纳入模型及评估，重点测量缺失或污染后的退化。

### 3. 为什么使用 ExtraSensory？

它提供真实在野采集、逐用户组织的多源传感器预计算特征，包含天然缺失和多标签上下文，适合用户独立鲁棒性研究。

### 4. 项目是实时系统吗？

不是。主线使用分钟级预计算特征，Streamlit 只做真实测试样本离线回放和故障注入。

## 数据与任务

### 5. 为什么是多标签而不是多分类？

坐着、使用电脑、在家和室内可以同时成立。模型需要为每个标签独立输出概率，因此使用 sigmoid，而不是只能选一个类别的 softmax。

### 6. 标签 NaN 为什么不能填成 0？

NaN 表示标签未知，不表示事件没有发生。填成 0 会制造错误负样本，因此损失和指标都要使用目标掩码。

### 7. 特征缺失和标签缺失有什么区别？

特征缺失表示传感器没有观测，影响模型输入；标签缺失表示真值未知，影响监督和指标。项目分别维护 feature mask 和 target mask。

### 8. 为什么只选 177 个特征？

项目按真实表头把可归入六个预声明模态的特征全部纳入，并明确排除手机磁力计、手表方向和低频测量等 48 列。不是根据测试性能挑列。

### 9. 为什么不使用原始信号？

ExtraSensory 主线公开了预计算特征，能在有限算力下完成完整五折和故障矩阵。但这也限制了对真实物理故障和端到端特征提取的结论。

## 防泄漏与训练

### 10. 为什么必须按用户划分？

同一用户不同时间的行为、设备和采集模式高度相关。随机按行划分会让模型在测试时看到训练用户，导致性能虚高。

### 11. 验证集和测试集分别做什么？

验证集负责早停和逐标签阈值选择。测试集只用于最终评估，不能反馈到模型、预处理器或阈值。

### 12. 为什么每个 fold 都要单独拟合预处理器？

不同 fold 的训练用户不同。若共享使用全数据统计量，测试用户的信息会进入缩放和填补过程，产生泄漏。

### 13. 为什么每个标签使用不同阈值？

标签流行率和可分性不同。统一 0.5 可能使稀有标签长期无法触发，因此在验证集固定网格上分别选择 F1 最优阈值。

### 14. 为什么类别权重也只能由训练集计算？

测试集标签分布属于未知信息。用测试分布计算正类权重会把测试信息引入训练目标。

## 模型结构

### 15. 为什么每个模态使用独立 Encoder？

六类数据的维度、物理含义和分布不同。独立编码后映射到统一 64 维空间，便于公平打分和加权融合。

### 16. feature mask 有什么用？

缺失值最终会填为零，而真实值也可能等于零。mask 告诉模型哪些数值是真实观测，避免把填充值当成有效信号。

### 17. 五个质量特征是什么？

可用性、观测比例、异常值比例、稳健 z-score 绝对值均值和最大值。它们都能从当前输入直接计算。

### 18. Reliability 和 Gate Weight 有什么区别？

Reliability 估计输入质量。Gate Weight 表示该模态对当前任务的使用程度，还受任务效用和其他模态竞争影响。

### 19. masked softmax 解决什么问题？

它保证不可用模态权重精确为零，并在剩余可用模态间重新归一化。全部模态不可用时直接报错。

### 20. 为什么 Quality-Aware 参数更多？

它在 Gated 架构上增加质量输入和 ReliabilityNet。其参数量为 134,875，比 Gated 的 120,085 多 14,790 个，但检查点仍约 0.55 MiB。

## 鲁棒性方法

### 21. Sensor Dropout 和普通 Dropout 有什么区别？

普通 Dropout 关闭网络中的部分神经元，主要用于防过拟合；Sensor Dropout 关闭整个输入模态，用于模拟传感器掉线。

### 22. 三类污染分别是什么？

Gaussian 是随机扰动，bias 是整体平移，scale 是整体放大或缩小。它们作用于标准化预计算特征。

### 23. 为什么故障元数据不能输入模型？

推理时不会知道“刚刚注入了哪种故障和强度”。如果把这些字段输入模型，实验会形成不现实的捷径。

### 24. 三个损失分别有什么作用？

分类损失学习标签；可靠度损失监督 ReliabilityNet；一致性损失限制同一样本在干净和污染视图间出现不合理的预测跳变。

## 实验与指标

### 25. 自然缺失和受控故障为什么都要做？

自然缺失反映数据实际状态。受控故障固定完整样本后只改变污染，便于控制变量。两者回答不同问题，不能互相替代。

### 26. 为什么主要使用 Macro-F1？

15 个标签高度不平衡。Macro-F1 先逐标签计算再等权平均，避免常见标签掩盖稀有标签表现。

### 27. 为什么不能只比较故障后的绝对 F1？

模型的干净起点不同。相对下降衡量各模型损失了自身正常能力的多少，更适合比较鲁棒性。

### 28. 主要结果是什么？

Robust Gated 的受控完整 Macro-F1 最高，为 0.6043。Quality-Aware 的自然缺失 Macro-F1 最高，为 0.5781，比 Gated 高 0.0110，并在五个 fold 中全部获胜。

### 29. 多模态移除结果如何？

随机移除三个模态时，Gated、Robust Gated 和 Quality-Aware 的相对下降分别为 12.87%、10.33% 和 9.45%。

### 30. 为什么不声称统计显著？

虽然有五个用户 fold，但可信矩阵只有一个训练种子，fold 也是同一数据集的相关划分。小差异只作描述性解释。

### 31. H4 为什么只有部分支持？

可靠度随三类污染增强而明显下降，但目标模态门控权重在 Gaussian 和 bias 下平均没有下降。因此可靠度响应成立，权重单调解释不成立。

### 32. 这是否说明 Quality-Aware 失败了？

不是。它在自然缺失和较强多模态缺失下取得最佳结果，可靠度也正确响应污染。负面发现只限制了对门控权重可解释性的表述。

### 33. 消融实验能证明每个组件有效吗？

不能。A0–A5 只有 fold 0、种子 13 和三 epoch，排序混合，只能作为工程筛查。因果结论需要五折、多种子消融。

## 工程与改进

### 34. 如何保证报告数字没有手填？

报告生成器只读取通过合同验证的 run 产物。表格保留 run ID，`source_map.csv` 和 `readme_source_map.csv` 记录产物与声明的来源。

### 35. Demo 如何防止伪造结果？

它会匹配检查点、解析后配置、预处理器、验证阈值、数据清单和真实测试集；缺失或哈希不一致时停止，没有随机预测回退。

### 36. 下一步最值得做什么？

优先为 B4/B5/P 增加多个种子，并运行五折消融；随后在第二个数据集和原始信号故障上验证，再测量移动端端到端延迟和能耗。

## 容易说错的五句话

| 不准确说法 | 准确说法 |
|---|---|
| 模型实时读取手机传感器 | Demo 离线回放预计算特征 |
| 模拟了真实传感器物理故障 | 对标准化特征执行受控污染 |
| Gate Weight 就是可靠度 | Gate Weight 是任务相关融合分配 |
| 五折证明了统计显著 | 五折、单种子提供描述性证据 |
| 所有组件都经过消融证明有效 | 消融只完成短期开发筛查 |
