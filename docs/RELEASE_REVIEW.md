# RobustSense 发布审查

## 审查结论

截至 2026-09-11，项目适合继续在本地或私有仓库中使用。公开重新分发仍需项目所有者先确定开源或专有许可证；当前 `LICENSE` 明确表示尚未授予许可证。该项属于发布决策，不影响实验和内部交付验收。

## 数据与隐私

- `data/` 整体被 Git 忽略，官方归档、解压数据、处理缓存和用户 UUID 不进入版本控制。
- `reports/data_audit/` 被忽略，避免逐用户审计派生产物进入公开提交。
- README、数据卡和模型卡只报告聚合统计，不暴露原始用户标识。
- Streamlit 在显示匿名用户 ID 前再次哈希，不显示原始 UUID。
- 发布前仍应复核 ExtraSensory 原始数据使用条款，不随仓库分发官方归档。

## 检查点与运行产物

- `runs/`、`artifacts/`、`*.pt`、`*.pth` 和 `*.ckpt` 均被 Git 忽略。
- 可信实验结果的 CSV、JSON 和 Markdown 摘要可保留，但公开时应确保其中不含逐用户原始标识。
- 若未来单独发布检查点，应同时发布匹配的模式、预处理器、阈值、配置与模型卡，不能只发布权重文件。

## 凭据与本机信息

- `.env`、`.env.*` 和 `configs/local.yaml` 被 Git 忽略。
- 源码和文档不应包含访问令牌、密码或个人绝对路径。
- 环境清单可能含操作系统、GPU 和软件版本，这些信息可用于复现，但公开前应检查是否包含用户名或私有路径。

## 许可证与引用

- `CITATION.cff` 已提供项目标题、版本和占位贡献者信息；公开发布前必须替换为真实作者。
- `LICENSE` 尚未授予重新分发权。项目所有者需要明确选择许可证，这是当前唯一明确的公开发布阻塞项。
- README 保留 ExtraSensory 官方页面、教程及原始论文链接。
- 技术报告相关工作引用 ExtraSensory、ModDrop 和缺失模态鲁棒学习论文。

## 复现与声明

- README 提供 Windows 环境安装、数据审计、开发运行、可信实验、报告重建和 Demo 启动命令。
- README 中的核心数值可通过 `reports/readme_source_map.csv` 映射到证据表、筛选条件和源 run ID。
- 模型卡和限制文档明确排除实时采集、物理故障仿真、医疗或个体决策等用途。
- 不得将五折、单种子描述性结果表述为统计显著或最先进性能。

## 发布前人工操作

1. 项目所有者选择许可证。
2. 将 `CITATION.cff` 中的占位贡献者替换为真实作者。
3. 在暂存区执行一次敏感信息扫描，确认没有强制加入被忽略的数据或检查点。
4. 如发布图表，确认字体许可和图中不含用户级标识。
