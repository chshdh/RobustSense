# RobustSense 局限性与声明边界

## 注册证据支持的结论

冻结的五折可信实验支持三项描述性结论：

1. 在注册的完整模态和自然缺失评估中，多源融合优于最佳单传感器；
2. 污染感知训练可降低受控模态移除造成的性能退化；
3. 显式质量建模能产生随注册特征空间污染单调变化的可靠度信号。

这些证据不足以支持最先进性能、因果、实时运行或生产就绪声明。

## 统计限制

可信矩阵包含五个用户独立 fold 和一个训练种子。fold 间标准差反映用户分区变化，但不反映种子级优化波动。五个 fold 是同一数据集的相关划分，不是五个独立数据集。Gated、Robust Gated 与 Quality-Aware 之间的小差异只能作描述性解释。

A0–A5 消融只使用一个 fold、一个种子和三个 epoch。其混合排序可作为工程证据，但不能隔离各组件的因果贡献。若要对单个组件作出结论，需要冻结的五折消融，最好还应加入多个种子。

## 数据限制

ExtraSensory 年代较早、标签为用户自报，且在人群、地域、设备和采集周期方面有限。标签可能缺失或含噪，某些 fold 中稀有标签的正例用户较少。传感器可用性可能与行为和设备使用相关，因此自然缺失未必随机。

项目没有外部数据集验证。更换手机、可穿戴设备、人群结构、环境或标签定义后，结果可能改变。

## 评估限制

受控场景从六模态完整的记录开始，有利于将同一 fold 内的差异归因于注入故障，但完整模态总体经过选择，可能更容易，或与自然不完整总体系统不同。自然和受控两条评估线必须同时报告。

Gaussian 噪声、bias drift 和 scale error 作用于标准化预计算特征，无法复现原始加速度计饱和、时序漂移、丢包、麦克风伪影、GPS 多径或设备专属故障机制。

逐标签阈值在验证集上选择后冻结。这能防止测试集重调，但不能保证域迁移后的校准性。

## 可解释性限制

Quality-Aware 的 ReliabilityNet 输出会随污染强度明显下降，但目标模态的融合权重在 Gaussian 噪声或 bias drift 下不会一致下降。门控权重还受模态竞争和下游分类效用影响，不能描述为经过校准的传感器可靠度或因果解释。

不可用模态被硬掩码为零，这是结构保证，不是学习得到的可解释性结果。

## 系统限制

全部实验均使用分钟级预计算特征。项目没有实现实时传感器采集，也未验证端到端特征提取。注册延迟只覆盖本地机器上的批量模型前向，不包括预处理、存储、传输、界面、功耗、热效应或移动硬件。

Phase 6 的 Streamlit 应用是离线回放和故障注入沙箱，必须使用真实数据样本和检查点，并明确标示为非实时系统。

## 负责任使用边界

RobustSense 不适用于医疗诊断、应急响应、就业、保险、执法、隐蔽监控或任何针对个人的决策。行为、位置衍生和音频衍生特征即便经过预计算和匿名化仍然敏感。

## 优先未来工作

1. 为 Gated、Robust Gated 和 Quality-Aware 增加多个种子；
2. 在全部五个用户 fold 上运行消融矩阵；
3. 测试原始信号及更接近真实设备的故障；
4. 在第二个数据集和更新的设备人群上评估；
5. 显式校准可靠度，并将其与门控权重解释分离；
6. 测量端到端流处理、能耗和端侧延迟。
