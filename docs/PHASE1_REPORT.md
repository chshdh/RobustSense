# Phase 1 报告

日期：2026-09-10（Asia/Shanghai）

## 结果

Phase 1 已基于 ExtraSensory 官方预计算特征版本和官方五折用户列表通过验收。实现能够安全解压归档、发现共享真实表头、应用穷尽且互斥的六模态模式、验证全部源数据行，并用一个命令重建完整的数据审计产物集。

本阶段没有训练模型，也没有查看测试性能。

## 来源与完整性

- 特征归档：225,374,973 字节；本地 SHA-256：`412d307bdf54a60dff81a705c2f25833889a46dca64a184e3b588ad99c69cb56`。
- fold 归档：10,803 字节；本地 SHA-256：`66183635452d8c1b250b570fba3000296bf29e4d54eda6af270d2b4f5a3b9ee6`。
- 两个哈希均标记为本地连续性检查，不声称是官方校验和。
- 未下载绝对位置附加包。
- 冻结真实表头前已检查官方 README 和入门 notebook；二者均说明首列为时间戳，随后是特征、允许缺失的 `label:*` 目标，最后是 `label_source` 元数据。

## 真实数据发现

- 60 名用户、377,346 个样本、278 列。
- 表头组成：1 个时间戳、225 个特征、51 个标签和 1 个元数据列。
- 六个选用模态共 177 个特征：手机加速度计 26、手机陀螺仪 26、手表加速度计 46、位置 17、音频 28、手机状态 34。
- 明确排除 48 个特征：手机磁力计 31、手表方向 9、低频测量 8。
- 全部 51 个标签列均符合 `{0, 1, NaN}`。
- 所有 `(user_id, timestamp)` 键唯一，全部用户文件按时间戳排序。
- 372,168 条记录可进入 Phase 2 预处理；其余 5,178 条的 15 个标签全部未知。没有记录缺少全部选用模态。
- 每个选用标签在每个官方 fold 中都有正例。`BICYCLING` 的正例用户数最少，为 25，因此预声明标签集保持不变。

## Fold 协议

已解析全部 20 个官方训练/测试/平台列表文件。五个测试 fold 两两互斥，每个官方训练列表都是对应测试列表的补集。外层 fold 0 以 fold 1 作为验证集，得到 36/12/12 名训练/验证/测试用户。每个列表均保存 SHA-256 摘要。

## 实现与测试

新数据模块覆盖安全原子化 ZIP 解压、UUID 解析、共享表头检查、严格正则映射、官方 fold 验证、分块行审计、哈希、清单、CSV 报告和 PNG 热力图。失败测试覆盖 Zip Slip、未映射/多重映射特征、非法标签、重复时间戳和空 fold 组件。集成夹具复现官方归档/文件结构并重建第 2.7 节全部九项产物。

Phase 2 必须只使用训练/验证用户拟合填补、稳健缩放统计量、类别权重和阈值，绝不能推断随机行划分或根据测试性能重新计算冻结模式。28 个音频列除 26 个 MFCC 汇总特征外还包含两个 `audio_properties` 特征；该真实表头发现现已纳入冻结模式。
