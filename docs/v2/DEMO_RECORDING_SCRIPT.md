# Demo 2.0 录屏/GIF 脚本（约 45 秒）

## 镜头顺序

1. **0–5 秒**：显示标题与黄色边界声明，口播“这是离线预计算测试特征回放”。
2. **5–12 秒**：侧栏选择 fold 0、seed 29、P2，展示真实 run、系统可靠度和接受/拒绝。
3. **12–20 秒**：关闭手机加速度，向手机陀螺仪注入 Gaussian σ=2，展示四模型同样本表。
4. **20–28 秒**：切换“质量与门控”，指出五维质量、reliability、utility 和最终权重。
5. **28–36 秒**：切换“持续故障时间轴”，展示故障前、中、后和真实 episode 响应。
6. **36–42 秒**：切换“聚合背景”，展示 63-mask 与混合故障五折三种子曲线。
7. **42–45 秒**：切换“产物合同”，强调 checkpoint、split 哈希和无随机回退。

## 一句话口播

“四个模型读取同一真实测试样本；P2 把任务 utility 和输入可靠度分开，并用验证集阈值决定
接受或拒绝。下方背景图来自 60 个核心 run 的真实压力评估，不是单样本演示结果。”

## 边界

录屏不得隐藏离线回放声明，不得把人工特征污染称为物理传感器故障，不得只展示 P2 有利
场景而省略 B5 在自然缺失和持续故障分类上更高的事实。
