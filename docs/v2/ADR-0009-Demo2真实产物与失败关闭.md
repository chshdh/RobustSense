# ADR-0009：Demo 2.0 只读取真实产物并失败关闭

- 状态：已接受
- 阶段：V2-5
- 日期：2026-09-19

## 决策

1. Demo 的 run 路径只能由 V2-4 核心登记表解析，不能由页面自行猜测目录。
2. B4、B5、P、P2 必须使用同一 fold、seed 和同一 `test.npz`；样本索引相同才允许比较。
3. checkpoint 合同、分类阈值、P2 拒绝阈值、评估清单或扩展产物任一缺失/不一致时，
   页面停止，不生成占位预测。
4. 模型输出直接来自真实 checkpoint。页面不得用随机数、固定示例概率或合成替代值回退。
5. 单样本故障在标准化预计算特征空间重放；63-mask、混合故障和持续故障背景读取
   V2-4 已冻结报告。页面必须明确这不是实时传感器采集或手机部署。
6. P2 展示独立 utility、可靠度、最终权重、系统可靠度以及验证集阈值决定的接受/拒绝；
   其他模型没有的量显示为“不适用”，不能伪造可比数值。

## 影响

Demo 可追溯、可离线重放，且能在面试中解释每个数字的来源。代价是首次加载四个 checkpoint
和测试 split 需要时间；任何产物漂移都会显式阻止页面运行。
