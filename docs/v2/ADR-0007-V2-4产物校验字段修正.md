# ADR-0007：V2-4 产物校验字段修正

- 状态：已接受，修正性核验前冻结
- 日期：2026-09-18
- 类型：产物治理修正，不修改训练或评估
- 父补充锁：`802b40efe005d09fb97c907a04e144c680a7ac75219c1286867053c1a5b56957`

## 问题

双任务调度器对 P2 完整产物做最终检查时，错误地从 `evaluation_manifest.json` 查找
`threshold_source_split`。P2 的该清单保存阈值文件哈希，但权威来源字段按既有合同位于
`thresholds.json` 的 `source_split`，并同时在 `test_metrics.json` 中记录。因此两个训练和
评估子进程均返回 0、且产物完整的 P2 单元被错误标记为 failed。

## 决策

1. 最终检查改为读取 `thresholds.json.source_split == "val"`；仍校验
   `evaluation_manifest.json`、身份、checkpoint、预测、拒绝阈值和风险覆盖产物。
2. 对原因为 `output_contract_error: Test thresholds are not validation-derived` 的单元，只在
   修正后的完整合同全部通过时改回 success；保留原 failed attempt，并追加
   `artifact_reconciliation_no_rerun` 审计记录。
3. 不重新训练、不重新选择阈值、不读取性能数值，也不删除失败历史。
4. 接管旧调度器中已经 running 的单元时，等待其训练状态文件完成，再执行原锁定的独立
   test 评估入口。

## 科研影响

该修正只更正产物字段位置，与模型表现无关。训练、测试预测和统计结果的字节内容不因本
修正而改变，因此不会形成按测试结果调参或选择模型。
