# RobustSense V2-5 Demo 2.0 协议

- 协议 ID：V2-5
- 父阶段：V2-4
- 状态：首轮 Demo 验收前冻结
- 日期：2026-09-19

## 1. 展示范围

Demo 必须展示：B4/B5/P/P2 同样本对比；每模态五维质量；模型实际输出的可靠度、utility
和最终融合权重；P2 系统可靠度与接受/拒绝；模态组合和混合故障控制；持续故障三阶段
时间轴；63-mask 和混合故障聚合背景；当前 checkpoint、run、fold、seed 和协议哈希。

## 2. 数据与模型边界

- 只回放 ExtraSensory 的离线预计算测试特征；
- 页面不得声称实时采集、原始信号建模、物理传感器仿真或端侧部署；
- 四个模型必须来自 V2-4 `success` 登记行；
- checkpoint、逐标签分类阈值和 P2 拒绝阈值必须通过保存合同；
- 分类阈值和拒绝阈值的来源必须为 validation；
- 页面选择样本可以改变索引，但预测值不得存在随机或合成回退。

## 3. 同样本比较

同一页面会加载所选 `fold × seed` 的四个模型，并验证：标签顺序一致、测试 split 文件哈希
一致、样本数一致。故障变换使用相同样本索引、模态集合、目标模态、故障类型与强度。

## 4. 报告背景

63-mask、混合故障与持续故障图表只读取 V2-4 扩展报告声明的 SHA-256 对应文件。
持续故障时间轴以 `pre → fault → post` 三阶段展示；有可靠度输出的模型可附加真实 episode
故障分数。图表不得把不存在的可靠度填成 0。

## 5. 验收

1. 四模型、五 fold、三 seed 的登记行均可解析；
2. 至少一个真实 `fold × seed` 四模型同样本推理通过；
3. P2 utility、可靠度、权重、系统可靠度与接受/拒绝均来自模型实际输出；
4. 不可用模态权重严格为 0，最终权重和为 1；
5. 63-mask、混合与持续故障图表通过来源哈希校验；
6. 删除或篡改必需产物的测试必须失败关闭；
7. Streamlit 健康检查通过，不存在随机预测回退；
8. Ruff、完整 pytest、依赖检查和 V1 不变性回归通过。
