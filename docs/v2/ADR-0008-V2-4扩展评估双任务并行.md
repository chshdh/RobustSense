# ADR-0008：V2-4 扩展评估采用双任务并行

- 状态：已接受
- 阶段：V2-4
- 日期：2026-09-19

## 背景

V2-4 核心 60 单元完成后，扩展压力评估仍需读取同一批冻结检查点，分别执行 63-mask、
60 个混合故障和 12 个持续故障场景。首个单元在协议不变的串行实现上完成，用时约 90 秒；
运行期间 GPU 利用率和显存占用均有较大余量。该观察只用于调度决策，没有读取或比较模型
性能指标。

## 决策

1. 后续扩展评估最多同时运行两个逻辑单元。
2. 每个逻辑单元仍调用原有 `run_v2_phase4_extended_unit.py`，场景、样本顺序、阈值、
   checkpoint 和输出合同全部不变。
3. 主控制器是登记表唯一写入者；工作线程只运行子进程并校验各自独立的输出目录。
4. 已完成的首个串行单元直接复用，不重复评估。
5. 任一单元显存不足、进程失败或产物合同不匹配时，记录为失败并停止以成功状态聚合；
   不允许静默缩小场景或改变批次语义。

## 影响

该变更只减少墙钟时间，不改变科研协议、结果数值定义或聚合顺序。并行上限、父协议哈希、
实现文件和本 ADR 在启动前写入独立执行修正锁。
