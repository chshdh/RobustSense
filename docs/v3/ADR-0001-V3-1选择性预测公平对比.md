# ADR-0001：V3-1 选择性预测公平对比

## 状态

已接受；在第一次 V3-1 正式测试评估前冻结。

## 背景

V2 已完成 B4、B5、P、P2 的五折三随机种子实验。P2 能输出系统可靠度并据此拒绝低可靠样本，但原 V2 结果主要回答“模型在固定验证集阈值下表现如何”，没有充分回答下面两个更适合面试与工程落地的问题：

1. 当系统只处理相同比例的高置信样本时，风险能否下降？
2. P2 学到的系统可靠度，是否比普通分类置信度更能识别错误样本？

如果先看测试结果再选择置信度公式、覆盖率或指标，会产生测试集选择偏差。因此 V3-1 必须先固定规则，再读取正式结果。

## 决策

1. 复用 V2-4 的 60 个 checkpoint、验证集分类阈值和自然缺失测试预测，不重新训练、不改写 checkpoint。
2. 四个模型都计算两种不依赖真实标签的通用置信度：平均二元确定度、平均归一化阈值间隔。
3. P2 额外使用模型真实输出的系统可靠度。由于 V2 的预测 Parquet 未保存该字段，V3-1 只对 P2 做一次确定性前向推理，并校验其概率与冻结 Parquet 一致。
4. 覆盖率固定为 0.05 到 1.00、步长 0.05；重点报告 0.80、0.90、0.95、1.00。
5. 主指标为归一化 AURC 和错误检测 AUROC；辅助指标为错误检测 AUPRC、固定覆盖率下的 masked BCE、Macro-F1 和 Micro-F1。
6. “样本发生错误”定义为：至少一个已知标签的预测错误。没有任何已知标签的样本不进入 V3-1 评估总体。
7. 主比较有两个：
   - P2 系统可靠度对 P2 平均二元确定度，用来隔离“选择器”本身的价值；
   - P2 系统可靠度对 B5 平均二元确定度，用来对比强基线的整体系统。
8. 所有预声明组合都完整报告，禁止从测试结果中只挑最好看的置信度规则。
9. 先在同一 fold 内对三个 seed 取均值，再对五个 fold 等权取均值。

## 公式

对第 `i` 个样本、第 `l` 个标签的预测概率 `p_il`，平均二元确定度为：

`c_i = 1 - mean_l(H(p_il) / log(2))`

其中 `H` 是二元熵。平均归一化阈值间隔使用验证集阈值 `t_l`：

- `p_il >= t_l` 时，间隔为 `(p_il - t_l) / (1 - t_l)`；
- `p_il < t_l` 时，间隔为 `(t_l - p_il) / t_l`。

P2 系统可靠度使用模型内部“模态融合权重 × 模态可靠度”的加权结果，不使用测试标签。

AURC 在实际覆盖率 0.05 到 1.00 的区间上用梯形积分，并除以区间宽度；越低越好。

## 后果

V3-1 能形成一组可审计、可复现、同覆盖率的选择性预测证据。它不会自动证明 P2 一定更好；如果 P2 系统可靠度没有胜过普通置信度，也必须如实报告，并把结果作为 V3-2 任务对齐可靠度设计的依据。
