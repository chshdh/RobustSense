# ADR-0005：V3-4 双策略决策层

## 状态

已接受，并在首次 V3-4 测试集评估前冻结。

## 背景

V3-3 说明同一个置信度分数难以同时擅长两件事：用户分组连续风险分数更适合降低接受样本的连续 BCE，普通二元确定度更适合识别“任一标签是否出错”。此前选择性曲线按测试集分数排序，适合研究比较，却不能直接变成部署阈值，因为线上系统看不到未来批次的整体排名。

## 决策

增加一个不训练神经网络的显式双策略决策层：

- `risk_control`：复用每个单元在 V3-3 由 validation 用户分组 OOF 选出的 Ridge 风险选择器。
- `error_alert`：使用 P2 输出的平均二元确定度。
- 使用者必须显式指定模式；系统不得根据测试数据或单个输入自动切换目标。
- 80%、90%、95% 三个目标覆盖率的接受阈值只从 validation 分数分位数产生。
- 阈值冻结后原样应用于 test；不得在 test 上重新排序、重新找分位点或补齐接受人数。
- 分数并列导致覆盖率超过目标时保留全部并列样本，并报告偏差，不做不稳定的随机拆分。

## 理由

这将“研究型排序能力”转换为可保存、可回放的部署合同，也诚实暴露 validation 到 test 的覆盖率迁移误差。双模式保留各自专长，避免用一个折中分数掩盖目标冲突。

## 后果

策略模式需要由业务场景选择。V3-4 只证明固定阈值决策层是否具备专长与覆盖率迁移能力，不声称能够自动推断业务目标，也不改变 P2 的原始预测概率。
