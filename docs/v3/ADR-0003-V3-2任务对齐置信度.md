# ADR-0003：V3-2 任务对齐置信度

## 状态

已接受；在第一次 V3-2 正式测试评估前冻结。

## 背景

V3-1 发现，P2 系统可靠度用于分类错误排序时，聚合 AURC 为 0.436400、错误检测 AUROC 为 0.508706，显著弱于 P2 普通分类确定度的 0.345228 和 0.727265，并且两个主指标都是 0/5 折胜出。

这说明原可靠度目标“模态是否干净”与最终任务目标“多标签分类是否会出错”不一致。下一步不应继续盲目增加神经网络复杂度，而应先验证：使用 validation 标签训练一个小型任务置信度层，能否把已有分类输出和传感器状态映射成更有效的拒绝分数。

## 决策

1. 不重训 P2 主模型，不修改 checkpoint。
2. 每个 fold/seed 只用该 run 的 validation 样本拟合标准化逻辑回归，目标为“至少一个已知标签预测错误”。
3. 固定 `C=1.0`、`solver=lbfgs`、`max_iter=1000`、不使用类别权重、不做超参数搜索。
4. `task_confidence_output_only` 使用 15 个逐标签二元确定度和 15 个逐标签阈值间隔，共 30 维。
5. `task_confidence_full` 在上述 30 维基础上加入 6 个模态可用性、6 个融合权重、6 个可用性掩码后的模态可靠度以及 1 个系统可靠度，共 49 维。
6. 逻辑回归输出错误概率，任务置信度定义为 `1 - P(error)`。
7. 正式 test 同时报告普通分类确定度、原 P2 系统可靠度、output-only 任务置信度和 full 任务置信度。
8. 主比较固定为 full 对普通分类确定度，以及 full 对 output-only；禁止根据 test 结果更换特征、正则强度或比较对象。

## 解释边界

V3-2 是 validation 拟合的后处理层，不是新的端到端主模型。它能证明任务对齐监督是否有价值，但不能单独证明原模态可靠度网络已经学会任务风险。full 对 output-only 的比较专门回答传感器可靠度特征是否提供额外增益。

## 后果

如果 full 与 output-only 都优于普通确定度，说明任务对齐监督有效；如果 full 进一步优于 output-only，才说明现有传感器可靠度信息在经过任务映射后仍有增量价值。如果 full 不优于 output-only，V3-3 应转向标签级可靠度或直接重设可靠度训练目标。
