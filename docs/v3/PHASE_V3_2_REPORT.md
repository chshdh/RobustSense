## 4. 结果解释

V3-2 的预声明主比较没有通过。full 相比普通分类确定度，AURC 增加 0.013015、错误检测 AUROC 下降 0.001249；AURC 为 0/5 折胜出。full 相比 output-only 也没有稳定增益，说明现有模态可用性、融合权重和可靠度特征没有在跨用户 test 上提供可靠的额外错误排序信息。

output-only 的错误检测 AUROC 为 0.728963，略高于普通确定度的 0.727265，但 AURC 从 0.345228 恶化到 0.356319。这说明“是否至少有一个标签错误”的逻辑回归目标与连续 masked BCE 风险并不完全一致。

后验诊断进一步显示：full 在 validation 内的平均错误检测 AUROC 为 0.785929，在 test 上降到 0.726016，平均落差 0.059913；output-only 的落差为 0.032721。full 的 49 个特征中只有 14 个在至少 80% 单元里保持同一系数方向，系数方向中位一致率仅 0.60。这些结果支持两个判断：validation 用户到 test 用户存在明显映射漂移；增加传感器特征扩大了过拟合空间。

因此下一阶段不应继续给同一个样本级逻辑回归堆特征，而应把训练目标直接改成连续风险或逐标签错误，并采用按用户交叉拟合来约束跨用户泛化。

## 5. 解释边界

任务置信度层只使用 validation 标签拟合；test 仅用于最终评分。full 对 output-only 的差异代表传感器状态和可靠度特征在逐标签输出之外的增量价值。

以上泛化差距和系数稳定性是完成预声明主分析后的诊断结果，不用于回头选择 V3-2 模型或修改主结论。
