# ADR-0004：V3-3 用户分组连续风险选择器

## 状态

已接受；在第一次 V3-3 正式测试评估前冻结。

## 背景

V3-2 的样本级逻辑回归使用“至少一个标签预测错误”作为目标。它在 validation 内取得较高 AUROC，但跨 test 用户的泛化落差达到 0.059913；同时，错误事件目标与连续 masked BCE 风险不一致，导致 output-only 的错误检测 AUROC略升而 AURC 恶化。

V3-3 必须同时解决目标错位、用户泄漏式拟合和高维不稳定三个问题。

## 决策

1. 监督目标改为每个 validation 样本的真实 masked BCE，直接对齐风险—覆盖率曲线。
2. 使用 4 折 GroupKFold，并以 `user_id` 分组；同一用户不得同时出现在某个交叉验证折的拟合部分和验证部分。
3. 风险模型固定为标准化 Ridge，solver 为 `svd`。
4. α 候选固定为 0.1、1、10、100、1000；按 validation 用户分组 OOF AURC 选择，平局选择更大的 α。
5. output-compact 只保留 6 个聚合分类输出特征；full-compact 额外加入 5 个聚合传感器特征，总计 11 维。
6. 两个特征家族各自完成 α 选择后，再按照 validation OOF AURC 选择 `grouped_risk_selected`；平局选择更简单的 output-compact。
7. 所有选择完成后才在全部 validation 上重拟合，并对冻结 test 做一次评估。
8. test 结果不得影响 α 或特征家族选择。

## 解释边界

分组交叉验证只发生在原 validation 用户内部，不能完全消除 validation 到 test 的总体分布差异；它的作用是让超参数和特征家族选择显式偏向跨用户稳定性。selected 是验证集选择结果，必须同时报告 output/full 两条原始曲线，不能只展示 selected。

## 后果

如果 selected 在五折聚合中同时降低 AURC、提高错误检测 AUROC，说明连续风险目标和用户分组选择能够修复 V3-2。如果 AURC改善但错误 AUROC 不升，说明模型更擅长排序连续损失而不是离散错误事件，这仍属于可解释的目标差异。
