# ADR-0002：V3-1 P2 回放批量修正

## 状态

已接受；在第一个成功 V3-1 单元生成前冻结。

## 触发原因

V3-1 原协议把 P2 可靠度回放 batch size 设为 2048，并要求重新前向推理的分类概率与 V2 冻结 Parquet 的最大绝对误差不超过 `1e-6`。

第一次 fold0/seed29 预检在 GPU 上得到 `1.2218952178955078e-6`，CPU 复核得到 `1.6391277313232422e-6`，都略高于闸门。两个执行都在写出曲线和摘要之前失败，因此修正前的成功正式单元为 0。

差异来自不同 batch size 下矩阵乘法的浮点舍入顺序。旧 V2 评估使用 run 配置中的 batch size 512；为了复现冻结预测，应恢复原始批量，而不是放宽一致性阈值。

## 决策

1. P2 可靠度回放 batch size 从 2048 改为 512。
2. 概率一致性绝对误差阈值继续保持 `1e-6`。
3. 置信度公式、覆盖率、指标、聚合、主比较和测试时禁止选模规则全部保持不变。
4. 原 V3-1 协议锁和原执行器保持不可变；使用独立的修正执行器与修正锁形成审计链。

## 影响

修正只影响重新计算 P2 系统可靠度时的数值复现路径，不改变模型参数、测试样本、分类概率、排序指标定义或结论规则。速度可能略慢，但能满足更严格的原产物一致性合同。
