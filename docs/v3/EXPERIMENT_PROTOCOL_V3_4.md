# RobustSense V3-4 实验协议：双策略固定阈值决策层

## 1. 研究问题

在不重新训练 P2、不接触测试标签调参的条件下，能否把 V3-3 已观察到的两类分数专长变成可部署的固定阈值策略，并量化 validation 到 test 的实际覆盖率迁移？

## 2. 冻结对象

- 继承 V3-3 已验收的 5 折 × 3 种子共 15 个 P2 单元。
- 测试预测、分类阈值和 V3-3 风险选择器均只读复用。
- 模式固定为 `risk_control` 与 `error_alert`。
- 目标覆盖率固定为 0.80、0.90、0.95。
- 推理批大小固定为 512；回放概率最大绝对差不得超过 `1e-6`。

## 3. 阈值生成与测试边界

对每个折、种子、模式和目标覆盖率，按 validation 置信度降序排列，接受人数取 `ceil(目标覆盖率 × validation 样本数)`。相邻边界分数不同时取中点；边界并列时使用并列分数作为阈值，因此允许 validation 覆盖率向上偏移。

固定阈值随后直接作用于 test 的每个样本。严禁使用 test 分数排名来凑目标人数，严禁根据 test 标签调阈值，也严禁自动挑选对当前 test 更有利的模式。

## 4. 指标

每个固定阈值报告：validation 实际覆盖率、test 实际覆盖率、test 覆盖率绝对误差、接受样本 masked BCE、Macro-F1、Micro-F1、接受样本错误率、拒绝样本错误精度和拒绝错误召回率。

“错误”定义为：在已有标签中至少一个标签经过 P2 冻结分类阈值后预测错误。

## 5. 聚合

先在每一折内对 3 个种子取均值，再对 5 折等权平均并报告折间标准差。模式差值也先按同一折同一目标覆盖率配对，再做五折汇总。

## 6. 首要假设与成功判据

1. 风险专长：`risk_control - error_alert` 的接受样本 masked BCE 小于 0。
2. 告警专长：`error_alert - risk_control` 的拒绝错误召回率大于 0。

每项假设必须至少在 3 个目标覆盖率中的 2 个满足正确方向，且这些覆盖率中候选策略至少胜出 3/5 折，才记为通过。两项均通过才称“双策略专长成立”。

覆盖率迁移另行判定：每种模式在全部折和目标覆盖率上的平均绝对误差不超过 0.05，记为达到部署准备线。科学假设是否通过与产物完整性验收相互独立。

## 7. 产物

每个单元保存 6 行结果、两个模式各三个验证集阈值、来源哈希和概率复现差。汇总保存折级结果、五折结果、配对比较、机器报告和中文阶段报告。
